WordLens原页面增强 · Windows

文档保持原样，选中文字就能查。

用于 Edge 内置 PDF 和其他不允许网页浮窗的文档页面。无需转换文件，也无需进入文字阅读器。

一次安装，三种方式

  1. 先下载本地辅助程序，双击运行。

    下载 Windows 辅助程序

  2. 把下方的扩展 ID 粘贴到安装窗口，点击安装 / 更新。

  3. 回到插件面板，开启原页面增强（Windows），选择查词模式。
    • 选中即查：选好单词、短语或句子后显示释义。
    • 快捷键查词：选中文字后按 Alt + W。
    • 右键查词：选中文字后，使用可用的 WordLens 右键菜单。

更新到 1.3.1 时，先关闭“原页面增强”，安装新版辅助程序，再在扩展管理页面重新加载 WordLens，然后开启增强并点击“重新连接”。“已连接”仅表示通信正常；选区读取失败时，面板会显示文字层或选区的具体状态。快捷键被占用时，可以在浏览器的扩展快捷键设置中调整。

读取范围与限制

组件只在启用后读取当前前台 Edge、Chrome、PowerPoint 或 WPS 中暴露给 Windows 无障碍接口的选区，不读取整份文档，不使用剪贴板，不记录键盘输入，不随 Windows 开机启动。组件与插件断开后会退出。

本机仅保留一份覆盖更新的诊断状态（版本、读取结果和计数），不含所选文字、文件名、地址或窗口标题，也不保存查询历史。

单词与已收录短语仍离线查询；联网翻译开启时，仅将所选文字发送至 MyMemory。本地组件没有网络连接。

扫描图片、未暴露可选文字的画布、受保护文档或部分 Office / WPS 查看器可能无法提供选区；此时会提示不能取词。右键菜单是否可用由原查看器决定。图片 OCR 不包含在此组件中。

如需停用，关闭插件面板的“原页面增强”。如需卸载注册，再次运行辅助程序，点击“卸载注册”；不影响原有文档和网页划词。
