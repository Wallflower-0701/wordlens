- 既有离线词典、翻译限额与隐私、语音逻辑测试继续通过。

Edge 页面验证：在回环地址承载阅读器页面，使用随包 PDF 示例完成加载、翻页、页码跳转及双击 Basic 显示真实词典音标和中文释义。页面中的 chrome API 使用测试适配器；划词由已安装的 WordLens 注入脚本提供。未通过自动控制重新加载已安装扩展；浏览器策略禁止访问扩展管理页，文件选择自动填入也缺少浏览器控制扩展的文件 URL 权限。因此本记录不宣称已完成已安装 1.2.0 的完整浏览器集成验证。
