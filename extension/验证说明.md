# 验证说明

版本 1.1.1 包含 12 项可重复运行的核心及翻译适配器测试（仓库根目录运行 npm test）。覆盖真实词库分片、音标和中文释义、短语、词形映射、输入验证、UTF-8 请求分段、缓存与并发请求、异常响应、网络失败、超时和额度错误。

开发期间通过 51 项 Chromium 浏览器检查，覆盖选词、选句、跨节点选择、Alt 模式、开关、输入框避让、iframe、边缘定位、断网词典查询和真实 MyMemory 翻译。

本地 HTML 支持已在 Microsoft Edge 155 的独立配置中验证：未授权时无浮窗，面板提示权限；授权并刷新后，单词 Basic 显示真实音标与中文释义，完整短语选区也可触发查询。原 HTML 文件未被修改。

发音测试验证调用与错误处理逻辑，未对不同系统语音包逐一试听。翻译质量与可用性取决于第三方服务。
