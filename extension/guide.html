点击空白或按 Esc 关闭。在工具栏面板中可切换 Alt + 选中模式。

装好或更新后，记得刷新网页

本地 HTML（file:///）需要在扩展详情中开启“允许访问文件 URL”，然后刷新文件页面。面板会显示文件访问是否开启，并提供扩展详情入口。

把扩展固定到工具栏，可以随时手动查询或暂停划词。在面板中可关闭“联网翻译”；关闭后只查询离线词典。

整句和未收录短语通过 MyMemory 翻译，仅发送选中的文字，无需 API Key，有免费使用限额。不保存查词或翻译历史。避免选中不希望发送给第三方的文字。

浏览器设置页、扩展商店和内置 PDF 阅读器不支持网页划词；可以使用工具栏面板。输入框与编辑器中的选择不会触发。

离线释义和音标来自 ECDICT。短语音标仅在词典有标注时显示；句子提供翻译和英语朗读。发音使用本地英语语音包。

没有识别到本地英语语音？

在 Windows 打开设置 → 时间和语言 → 语音 → 管理语音 → 添加语音，选择英语（美国）或英语（英国），等待下载完成。不同 Windows 版本的按钮名称可能略有不同。

安装完成后，彻底退出并重新打开 Edge / Chrome，再在插件面板点击“重新检查”和“测试发音”。如果浏览器仍在后台运行，可在任务栏通知区域退出浏览器，或重启电脑后再试。

电脑上已有 Microsoft Zira Desktop，也可能仍需添加这里的英语语音：旧版桌面语音不一定出现在浏览器使用的现代语音列表中。只安装英语键盘、显示语言或语音识别，也不等于已安装英语文本转语音。

插件只使用本地英语语音。检查未通过时，不会改用中文语音或自动发送文字给在线语音服务。参考 微软语音安装说明。
