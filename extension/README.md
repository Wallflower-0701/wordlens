# WordLens 1.1.1 划词词典与翻译

选中网页上的英文单词、短语或句子，在旁边查看音标、中文释义或中文翻译，并点击扬声器朗读英文。

## 安装与更新（Chrome / Microsoft Edge）

1. 将 `WordLens-1.1.1.zip` **全部解压**到固定目录。
2. 在浏览器地址栏输入 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge），开启**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择包含 `manifest.json` 的 **wordlens 文件夹**。
4. 插件会打开使用指南。刷新其他已打开的网页，再双击单词或拖选短语、句子。

如果已经安装旧版：把新版 `wordlens` 中的文件复制到原来加载的 `wordlens` 文件夹并覆盖，在扩展管理页点击 WordLens 的**重新加载**按钮，再刷新网页。也可以移除旧版后重新加载新版，但原设置可能丢失。新增的翻译服务访问权限如触发浏览器提示，需要允许该权限，联网翻译才能工作。

不要移动或删除已加载的文件夹；浏览器会直接使用这些文件。可以将 WordLens 固定到工具栏。

Chrome 官方说明：https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked

## 本地 HTML 页面（file:///）

1. 安装或更新到 1.1.1 后，打开 `edge://extensions` 或 `chrome://extensions`。
2. 找到 WordLens，打开**详细信息**，开启**允许访问文件 URL**（也可能显示“允许访问文件网址”）。
3. 回到本地 HTML 页面并刷新，再双击英文单词或拖选短语、句子。

面板中会显示文件访问权限是否开启，点击“扩展详情”可直接打开该扩展的设置。这是浏览器控制的权限，需要用户在浏览器中开启，扩展不能自行打开它。

## 三种查询

- **单词**：使用离线词典显示中文释义、词典音标和英语发音；未知单词会提示未收录。
- **短语**：优先查询离线词典，例如 `take care of`、`in front of`、`look forward to`。未收录时使用联网翻译。词典有短语音标时显示音标，否则显示“短语释义”。
- **句子**：拖选整句英文，显示中文机器翻译，并可朗读所选英文。句子不生成未经词典核实的整句音标。

每次最多 **2000 个字符**。长文字会按 UTF-8 字节数和句子/单词边界分段发送，避免服务单次请求超限；过长的文字在查询前拒绝，不会静默截取前半句。建议按句或短段选择，翻译质量取决于第三方服务，长文本分段可能影响上下文。

## 操作与设置

- 默认选中即显示；点击空白、按 Esc、点击 × 或滚动网页关闭浮窗。
- 工具栏面板可手动输入单词、短语或句子。**Enter 查询，Shift + Enter 换行**。
- “网页划词 / 划句”开关可暂停自动浮窗，手动查询仍可使用。
- “触发方式”可切换成 **Alt + 选中**，减少打扰。
- “联网翻译”默认开启。关闭后只查询离线词典，未收录的短语/句子会提示开启联网翻译。
- 发音偏好可选英式优先或美式优先；没有对应口音时，回退到其他本地英语语音。音标以词典标注为准，不随口音偏好改变。

## 离线、联网与隐私

本地词库包含 **399,213 个单词和 357,828 个短语条目**，以及 265 个无独立词条的词形映射。词库查询不联网。

句子及未收录的短语使用 **MyMemory** 的英文 → 简体中文接口，无需账号和 API Key。只发送你当前选择或在面板中输入的文字，不发送网页地址、整页内容或周围上下文。请求不携带网站 Cookie。

MyMemory 是第三方在线服务，有免费使用限额；网络不可用、超时、额度用尽时会明确提示，离线词典继续可用。第三方服务可能记录请求，处理规则见其服务条款。不希望发送给第三方的文字，请先关闭“联网翻译”。

- API 文档：https://mymemory.translated.net/doc/spec.php
- 使用限额：https://mymemory.translated.net/doc/usagelimits.php
- 服务条款：https://mymemory.translated.net/doc/en/tos.php

本扩展不保存查词或翻译历史，不含广告、跟踪或统计。设置仅保存在本机；少量翻译结果仅在后台内存缓存，关闭联网翻译会清除缓存并取消未完成请求。

发音使用 `chrome.tts`，只选择本地英语语音，不使用远程语音引擎。若无法发音，请在 Windows **设置 → 时间和语言 → 语音**或系统语言/辅助功能设置中添加英语语音包，再重启浏览器。

## 支持范围

Chrome / Edge 114 及以上的普通 HTTP / HTTPS 网页、本地 HTML 文件（需开启文件访问），以及允许内容脚本运行的 iframe。支持双击、鼠标拖选、跨 HTML 文本节点选择和 Shift + 方向键选择。

输入框、密码框和富文本编辑区域中的选择不会自动触发。浏览器设置页、扩展商店、内置 PDF 阅读器、扫描图片、Canvas 文字和封闭 Shadow DOM 中的文字不支持网页划词；可以使用面板手动查询。本地 PDF 仍受内置 PDF 阅读器限制，开启文件访问不会改变这一点。

当前是英文 → 中文，不自动判断其他语言。

## 所需权限

- `storage`：保存开关、触发方式和口音偏好。
- `tts`：本地英语朗读。
- `https://api.mymemory.translated.net/*`：只允许向这一翻译服务发出联网请求。
- 普通网页内容脚本访问：读取所选文字与位置、显示浮窗；安装时浏览器会显示网页访问权限提示。

## 故障排查

- **刚安装/更新后无反应**：刷新网页，确认网页划词已开启，检查是否启用了 Alt 模式。
- **本地 HTML 无反应**：确认版本为 1.1.1，并在扩展详情开启“允许访问文件 URL”，然后刷新本地文件。
- **短语/句子无法翻译**：确认联网翻译开启、网络能访问 MyMemory；查看是否有额度用尽或服务超时提示。
- **缺少音标**：部分词条没有音标，句子只提供翻译和朗读。
- **特殊网页无浮窗**：使用工具栏面板手动查询。
- **无法朗读**：检查系统的本地英语语音包。

## 源码与数据

扩展无需构建或安装 Node.js，直接加载即可。`manifest.json` 是 Manifest V3 配置；`background.js` 调度本地词典与发音；`core.js` 提供文本规范化、词典与分段逻辑；`translation.js` 处理固定翻译接口、限额、超时和内存缓存；`content.js` 是网页浮窗；`popup.*` 是面板；`guide.*` 是指南。

ECDICT 来源：https://github.com/skywind3000/ECDICT

词库按前两个字母拆分并 gzip 压缩，按需读取分片。条目数量、原始文件 SHA-256 与格式见 `data/metadata.json`。保留具有中文释义的单词和短语，长度不超过 160 字符，允许内部空格、撇号和连字符。
