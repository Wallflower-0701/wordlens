# WordLens 1.3.7 划词词典与翻译

选中网页上的英文单词、短语或句子，在旁边查看音标、中文释义或中文翻译，并点击扬声器朗读英文。

## 安装与更新（Chrome / Microsoft Edge）

1. 将 `WordLens-1.3.7.zip` **全部解压**到固定目录。
2. 在浏览器地址栏输入 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge），开启**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择包含 `manifest.json` 的 **wordlens 文件夹**。
4. 插件会打开使用指南。刷新其他已打开的网页，再双击单词或拖选短语、句子。

如果已经安装旧版：把新版 `wordlens` 中的文件复制到原来加载的 `wordlens` 文件夹并覆盖，在扩展管理页点击 WordLens 的**重新加载**按钮，再刷新网页。也可以移除旧版后重新加载新版，但原设置可能丢失。新增的翻译服务访问权限如触发浏览器提示，需要允许该权限，联网翻译才能工作。

不要移动或删除已加载的文件夹；浏览器会直接使用这些文件。可以将 WordLens 固定到工具栏。

1.3.5 修复网页 / 本地 HTML 中点击朗读后出现第二张卡片的问题。更新扩展并刷新 HTML 页面即可生效；Windows 辅助组件继续使用 1.3.4，无需重新安装。网页释义卡片存在且当前文档获得焦点时，不再重复显示辅助浮窗，朗读仍由当前卡片发起。

1.3.7 修复 HTML 点击朗读重复显示辅助卡片：网页浮窗打开期间持续登记并优先显示，关闭或离开页面后释放；包括迟到的取词失败提示。升级后请重新加载扩展并刷新 HTML 页面，无需重装 Windows 辅助组件。

1.3.6 在面板“阅读偏好”增加 **单词自动朗读** 开关，默认关闭并保存选择。开启后，网页 / 本地文档 / 原页面增强或面板查询成功显示单词释义时自动朗读所选原词。短语、句子和失败查询不会自动发音，手动朗读按钮一直保留。没有本地英语语音时会提示，释义仍可查看。

Chrome 官方说明：https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked

## 本地 HTML 页面（file:///）

1. 安装或更新到 1.3.7 后，打开 `edge://extensions` 或 `chrome://extensions`。
2. 找到 WordLens，打开**详细信息**，开启**允许访问文件 URL**（也可能显示“允许访问文件网址”）。
3. 回到本地 HTML 页面并刷新，再双击英文单词或拖选短语、句子。

面板中会显示文件访问权限是否开启，点击“扩展详情”可直接打开该扩展的设置。这是浏览器控制的权限，需要用户在浏览器中开启，扩展不能自行打开它。

## 保留原页面使用（Windows）

在面板选择“查词模式”：选中即查、快捷键查词（默认 Alt + W）、右键查词。普通网页无需辅助组件；Edge 内置 PDF 等受内容脚本限制的页面需要开启“原页面增强”。

点击面板的“安装 / 使用帮助”，运行随包附带的 `native/WordLens.Native.exe`，粘贴帮助页显示的扩展 ID 并安装。然后在面板开启“原页面增强（Windows）”，原文档保持原样，不进入文字阅读器。

标准模式读取前台 Edge、Chrome、PowerPoint 或 WPS 暴露的选区，不使用剪贴板。复制模式须主动选择，仅在前台支持应用按 Ctrl+C 后读取新复制的纯文本；不读历史、不改写剪贴板、不自动模拟复制，不记录键盘文字。组件不会随系统启动，通过当前用户的浏览器通信注册按需启动，断开后退出。关闭开关可停用；再次运行组件可卸载注册。

1.3.3 的选区位置校验经用户反馈仍会取到错误文字、响应缓慢；1.3.4 新增复制模式后，用户仍反馈内容不符。当前修复尚未成功，保持测试草稿，不作正式版本发布。复制模式需要按 Ctrl+C，仅绕开无障碍文字层，不保证解决目标 PDF 的取词问题。扫描图片、受保护或禁止复制的文档不保证可用。原有文字阅读器保留为可选入口。

1.3.4 校验鼠标松开的位置、选区矩形与文字范围，拒绝其他位置的旧选区。普通未就绪情况最多读取三次，位置不符时最多五次；文字层超时后最多自动重启组件两次，连接恢复后请重新选词。浮窗标题保留实际选中的英文，原形释义单独标注。升级时先关闭增强、安装新版组件，再重新加载扩展并开启增强、重新连接。面板中的“已连接”仅代表通信正常；读取失败会显示具体状态。本机只覆盖保留一份不含选中文字、文件名、URL 或窗口标题的诊断状态，不保存查询历史。

## 本地 PPT、PDF、Word 与文本

点击工具栏的 **WordLens → 打开本地文档**，在阅读器中再次点击 **打开本地文档**，选择文件后双击英文单词或拖选短语、句子。PPTX / PDF 可逐页阅读，也可以按页码跳转。使用文件选择打开文档，不需要开启“允许访问文件 URL”。

- 支持 PPTX、PDF、Word（DOCX），以及 TXT、MD、CSV、TSV、LOG、JSON、XML、TEX 等 UTF-8 / 带 BOM 的 UTF-16 文本。
- PDF 默认使用 **原排版 · 精准划词**，保留公式、图形和页面版式，可缩放或切换 **文字阅读版**。绘制原页并生成可选文字层，不修改原文件。标准 Unicode 合字自动展开；已确认的 TeX 字体控制编码经绘制字体与字符证据校验后修正，未知编码不猜测。
- 阅读器中可直接选词，无需 Windows 辅助组件，也无需按 Ctrl+C / Alt+W；网页划词总开关与 Alt 触发偏好仍有效。原排版模式是单独的阅读入口，不能视为 Edge 内置 PDF 查看器取词问题已修复。
- PPTX / DOCX 和 PDF 的文字阅读版不保留图片、复杂公式和原排版，文字顺序可能与复杂多栏版式不同。DOCX 按段落与表格文字顺序阅读，不推测 Word 分页。
- 旧版 .ppt / .doc 请先另存为 .pptx / .docx 或含文字的 PDF；其他文档可导出为含文字的 PDF，表格可导出为 CSV。
- 扫描页、图片文字暂不做 OCR；PDF 原排版模式仍可显示页面，没有可选文字时会提示。暂不支持加密文档。单文件最大 50 MB，PPTX / PDF 最多 2000 页，内容过多时请拆分。
- 文档在本机提取文字，不修改原文件、不上传整份文件，也不执行文档中的脚本或加载外部链接。联网翻译开启时仍仅发送所选文字。

Edge 的内置 PDF / Office 查看器可能不允许注入网页浮窗，Windows 可开启“原页面增强”在原文旁查词；插件阅读器仍可选用。在提供扩展右键菜单的页面，也可以选中文字后右键选择 **用 WordLens 查词 / 翻译所选文字**。选区仅通过扩展会话存储短暂传递，使用后删除，超过两分钟视为过期，不把文字放进网址或持久历史。

## 三种查询

- **单词**：使用离线词典显示中文释义、词典音标和英语发音；未知单词会提示未收录。
- **短语**：优先查询离线词典，例如 `take care of`、`in front of`、`look forward to`。未收录时使用联网翻译。词典有短语音标时显示音标，否则显示“短语释义”。
- **句子**：拖选整句英文，显示中文机器翻译，并可朗读所选英文。句子不生成未经词典核实的整句音标。

每次最多 **2000 个字符**。长文字会按 UTF-8 字节数和句子/单词边界分段发送，避免服务单次请求超限；过长的文字在查询前拒绝，不会静默截取前半句。建议按句或短段选择，翻译质量取决于第三方服务，长文本分段可能影响上下文。

## 操作与设置

- 默认选中即显示；点击空白、按 Esc、点击 × 或滚动网页关闭浮窗。
- 工具栏面板可手动输入单词、短语或句子。**Enter 查询，Shift + Enter 换行**。
- “网页划词 / 划句”开关可暂停自动浮窗，手动查询仍可使用。
- “触发方式”可切换成 **Alt + 选中**，减少打扰。
- “单词自动朗读”可自行开启或关闭，默认关闭；旧版设置升级后保持关闭。快速换词时，尚在等待语音初始化的旧朗读请求会被丢弃。
- “联网翻译”默认开启。关闭后只查询离线词典，未收录的短语/句子会提示开启联网翻译。
- 发音偏好可选英式优先或美式优先；没有对应口音时，回退到其他本地英语语音。音标以词典标注为准，不随口音偏好改变。

## 离线、联网与隐私

本地词库包含 **399,213 个单词和 357,828 个短语条目**，以及 265 个无独立词条的词形映射。词库查询不联网。

句子及未收录的短语使用 **MyMemory** 的英文 → 简体中文接口，无需账号和 API Key。只发送你当前选择或在面板中输入的文字，不发送网页地址、整页内容或周围上下文。请求不携带网站 Cookie。

MyMemory 是第三方在线服务，有免费使用限额；网络不可用、超时、额度用尽时会明确提示，离线词典继续可用。第三方服务可能记录请求，处理规则见其服务条款。不希望发送给第三方的文字，请先关闭“联网翻译”。

- API 文档：https://mymemory.translated.net/doc/spec.php
- 使用限额：https://mymemory.translated.net/doc/usagelimits.php
- 服务条款：https://mymemory.translated.net/doc/en/tos.php

本扩展不保存查词或翻译历史，不含广告、跟踪或统计。设置仅保存在本机；少量翻译结果仅在后台内存缓存，关闭联网翻译会清除缓存并取消未完成请求。

发音使用 `chrome.tts`，只选择本地英语语音，不使用远程语音引擎。面板提供“重新检查”“测试发音”和安装帮助。

若提示浏览器未识别到本地英语语音，请在 Windows **设置 → 时间和语言 → 语音 → 管理语音 → 添加语音**中选择**英语（美国）**或**英语（英国）**，等待下载完成，再彻底退出并重新打开浏览器。浏览器仍在后台运行时，可从任务栏通知区域退出，或重启电脑。

已有 Microsoft Zira Desktop 也可能仍需添加这里的英语语音：浏览器优先读取现代 OneCore 语音目录，旧桌面语音不一定出现在浏览器列表中。只安装英语键盘或语音识别也不等于安装英语文本转语音。参考[微软语音安装说明](https://support.microsoft.com/en-us/accessibility/windows/narrator/appendix-a-supported-languages-and-voices)。

## 支持范围

Chrome / Edge 114 及以上的普通 HTTP / HTTPS 网页、本地 HTML 文件（需开启文件访问），以及允许内容脚本运行的 iframe。支持双击、鼠标拖选、跨 HTML 文本节点选择和 Shift + 方向键选择。

输入框、密码框和富文本编辑区域中的选择不会自动触发。浏览器设置页、扩展商店、内置 PDF 阅读器、Canvas 文字和封闭 Shadow DOM 中的文字不支持直接注入浮窗。请使用插件阅读器、可用的扩展右键菜单或面板手动查询。本地文档阅读建议使用当前版本的 Edge / Chrome。

当前是英文 → 中文，不自动判断其他语言。

## 所需权限

- `storage`：保存开关、触发方式和口音偏好。
- `tts`：本地英语朗读。
- `contextMenus`：为所选文字添加右键查词入口。
- `nativeMessaging`：仅在用户开启原页面增强后，连接已安装的本地选区辅助组件。
- `https://api.mymemory.translated.net/*`：只允许向这一翻译服务发出联网请求。
- 普通网页内容脚本访问：读取所选文字与位置、显示浮窗；安装时浏览器会显示网页访问权限提示。

## 故障排查

- **刚安装/更新后无反应**：刷新网页，确认网页划词已开启，检查是否启用了 Alt 模式。
- **本地 HTML 无反应**：确认扩展版本为 1.3.7，并在扩展详情开启“允许访问文件 URL”，然后刷新本地文件。
- **短语/句子无法翻译**：确认联网翻译开启、网络能访问 MyMemory；查看是否有额度用尽或服务超时提示。
- **缺少音标**：部分词条没有音标，句子只提供翻译和朗读。
- **PDF / PPT 原页面无浮窗**：确认扩展版本为 1.3.7、辅助组件为 1.3.4，查词模式为“选中即查”，触发方式为直接选中，原页面增强已开启并连接。先在 PDF 重新选择英文；仍无反应时查看面板的文字层 / 选区状态，或选中后尝试 Alt+W。部分查看器可能不暴露选区，文字阅读器仍可作为可选入口。
- **特殊网页无浮窗**：尝试可用的扩展右键菜单，或使用工具栏面板手动查询。
- **无法朗读**：在面板重新检查本地英语语音；未识别到时，按上面的步骤添加英语文本转语音，再彻底重启浏览器。

## 源码与数据

扩展无需构建或安装 Node.js，直接加载即可。`manifest.json` 是 Manifest V3 配置；`background.js` 调度本地词典与发音；`core.js` 提供文本规范化、词典与分段逻辑；`translation.js` 处理固定翻译接口、限额、超时和内存缓存；`speech.js` 处理本地英语语音发现、重试与播放状态；`content.js` 是网页浮窗；`popup.*` 是面板；`guide.*` 是指南。

ECDICT 来源：https://github.com/skywind3000/ECDICT

词库按前两个字母拆分并 gzip 压缩，按需读取分片。条目数量、原始文件 SHA-256 与格式见 `data/metadata.json`。保留具有中文释义的单词和短语，长度不超过 160 字符，允许内部空格、撇号和连字符。

扩展源码授权见 `LICENSE.txt`；词典原始开源声明完整保存在 `ECDICT-LICENSE.txt`。本项目未发布到扩展商店，安装包为开发者模式加载的完整源码版。

本地 PDF 解析使用随扩展附带的 Mozilla PDF.js 6.4.299。第三方许可见 `THIRD_PARTY_NOTICES.md` 与 `vendor/pdfjs/` 中保留的许可文件。
